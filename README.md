# Week-11-mini-project-datawarehouse

## Project Overview

โครงการนี้เป็นส่วนหนึ่งของรายวิชา **Business Idea Creation** โดยมีวัตถุประสงค์เพื่อวิเคราะห์ข้อมูลอุตสาหกรรมปาล์มน้ำมันผ่านการสร้าง Dashboard เชิงเล่าเรื่อง (Storytelling Dashboard) ด้วย Power BI

Dashboard นี้นำเสนอข้อมูลภาพรวมของอุตสาหกรรมปาล์มน้ำมันโลก และวิเคราะห์สถานการณ์ของประเทศไทย เพื่อใช้เป็นข้อมูลสนับสนุนการตัดสินใจทางธุรกิจ

---

## Objectives

* วิเคราะห์แนวโน้มการผลิตปาล์มน้ำมันของโลก
* เปรียบเทียบประเทศผู้ผลิตปาล์มน้ำมันรายสำคัญ
* วิเคราะห์สถานการณ์การผลิตปาล์มน้ำมันของประเทศไทย
* สร้าง Dashboard เชิงเล่าเรื่องเพื่อสนับสนุนการตัดสินใจทางธุรกิจ

---

## Dataset

แหล่งข้อมูลที่ใช้ในโครงการ:

**FAOSTAT – Crop Production, Yield, Harvested Area (Oil Palm Fruit)**

ข้อมูลประกอบด้วย:

* Country
* Year
* Production (tonnes)
* Yield (kg/ha)
* Area harvested (ha)

---

## Dashboard Structure

### Page 1: Global Palm Oil Industry Overview

นำเสนอภาพรวมอุตสาหกรรมปาล์มน้ำมันโลก

ประกอบด้วย:

* Total Production
* Average Yield
* Total Harvested Area
* Number of Countries
* Production Trend
* Top Producing Countries

---

### Page 2: Thailand Palm Oil Analysis

วิเคราะห์สถานการณ์การผลิตปาล์มน้ำมันของประเทศไทย

ประกอบด้วย:

* Thailand Production
* Thailand Yield
* Harvested Area Analysis
* Production Trend
* Yield Trend
* Business Insights
